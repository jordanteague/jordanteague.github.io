01 · Building

Open-source tools that encode legal judgment for AI agents.

Legal AI, built in the open

Each of these takes a piece of a lawyer's judgment and makes it something an AI agent can apply the same way every time.

Claude skill · Trademark clearance

TMrex

Screens a proposed mark and reports on registrability. It searches a local copy of the full USPTO register, about 14 million case files synced twice a day, plus the web and domain names for unregistered use.

Scope
Screening-level U.S. clearance
Searches
USPTO register, web, domain names
Released as
Open source
Source
github.com/jordanteague/TMrex

Claude skill · Discovery review

ROGbuster

Reads the other side's discovery responses, flags every gap, and drafts the meet-and-confer letter.

Input
The other side's discovery responses
Output
Gap list and meet-and-confer letter
Released as
Open source
Website
rogbuster.com
Source
github.com/jordanteague/ROGbuster

Specification + Claude skill · AI playbooks

Judgment Compiler

Compiles a lawyer's judgment into a structured playbook that AI review agents can apply consistently, so expertise is written down once and reused across workflows.

Input
An interview or a starting draft
Output
Schema-validated playbooks
Platform
Neutral; ships with a Claude skill
Source
github.com/jordanteague/judgment-compiler

Pilot benchmark · Evaluation

TrademarkBench

Scores Claude's predictions against real examiner decisions, with and without trademark-register search.

Question
Can Claude predict USPTO examination outcomes?
Sample
90 applications examined after the model's training cutoff
Status
Pilot; results are directional
Source
github.com/jordanteague/trademarkbench
